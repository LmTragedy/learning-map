# Cursors

`arrow.svg` and `pointer.svg` are the `default` and `pointer` cursors from
[ComixCursors](https://gitlab.com/limitland/comixcursors) (right-handed, White
colour scheme, opaque), copyright © 2006–2013 Jens Luetkens and others.

Changes from the upstream sources: colours and outline width applied as in the
upstream `White.CONFIG` / `Opaque.INCLUDE` build settings, shadow blur reduced,
editor metadata removed, and the view box cropped to a 32×32 cursor.
