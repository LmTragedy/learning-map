# Learning Map visual language

Direction: quiet learning console (Technical Product Console / operational dashboard). The supplied PNG is the sole visual anchor: deep navy canvas, turquoise completed paths, amber current/available nodes, muted locked branches, left navigation and right node details. No invented progress. Provisional wordmark: Learning Map / 知识地图.

Tokens live as CSS variables at the top of `frontend/src/styles.css`: surfaces `--bg` #0c1421, `--surface` #101b2a, `--raised` #17263a, `--border` #283a4f; text `--text` #edf3f8, `--text-2` #b9c7d5, `--muted` #8597ab; `--accent` #35d3c5 (passed, focus and the single primary action per screen); `--danger` #ff9393. Learning states each pair a color, an icon and a word: 可学习 amber `--st-new` (CircleDot), 学过 `--st-studied` (BookOpen), 自我掌握 blue `--st-mastered` (BadgeCheck), 验收通过 teal `--st-passed` (CircleCheck), 未解锁 grey dashed `--st-locked` (Lock); the words come from `src/status.ts`. Type scale `--fs-xs` 12 / `--fs-sm` 13 / `--fs-md` 14 / `--fs-lg` 16 / `--fs-xl` 20px, nothing smaller than 12px; radii `--r-sm` 6, `--r-md` 8, `--r-lg` 12. One border per block (no card inside a card); selection is an outline plus an amber bar, never a teal fill. Info callouts are neutral, not teal. No marketing hero, fake statistics or decorative gradients.

Desktop shell (fixed to the window height, each pane scrolls on its own): 232px sidebar with the course list and per-course progress on top, and 学习档案 / Obsidian 笔记 / 设置 / AI status at the bottom; a two-row course header (title + version, materials, node count, progress; then 复习所选 PDF, 导入材料 and a ⋯ menu holding 更新地图, 已导入材料, 保存版本, 版本历史, 删除课程); the view switch and search (Ctrl+K) above the map; a 400px node panel with 找回思路 in its top right. Review mode shows as an amber chip in the header with 编辑 / 退出. Every feature has one entry point. Under 780px the sidebar becomes a drawer, the node panel a bottom sheet, and 地图 / 复习 / 档案 / 设置 a bottom tab bar. Inputs use visible labels, focus outlines and text error messages; processing disables the dependent action and reports errors; disabled controls are 45% opaque and say why. Buttons use verbs and an icon. Actual local records drive all counts. Preserve React Flow attribution. Motion is limited to state changes and disabled for reduced-motion preferences.
