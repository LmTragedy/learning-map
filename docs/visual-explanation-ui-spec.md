# 视觉规格（一比一）：AI 任务与恢复 · 原文例子与过程图

日期：2026-11-03。配套文档：[visual-explanation-ui.md](visual-explanation-ui.md)（方案与接口语义）。本文件只描述**长什么样、多大、什么颜色、什么文字、怎么动**，实现时逐条照做即可。接口字段以 Codex 后端定稿为准，本文出现的状态名均为前端语义名。

实施补充（2026-11-03）：聚焦视图使用 Radix dialog portal，距视口四边 16px、遮罩位于工作台外，避免窄工作台或任务提示挤掉图像。来源过程逐页显示已存 PDF/image 原图和该页的引用状态；不添加未保存的 AI 重绘。其余保留原视觉方案，实际数据接口见 [api-contract.md](api-contract.md)。

阅读约定：
- 所有尺寸单位是 CSS px；“高 32”= `height: 32px`。
- 颜色写成 **token（实际值）**。实际值取自当前 `index.css`（未分层，优先级最高）和 `styles.css`；两处同名时以 `index.css` 为准（例如 `--border` 实际是 `#34343b`）。
- 字体：`--font-sans` = "Noto Sans SC Variable", "Geist Variable", "PingFang SC", "Microsoft YaHei UI"；数字一律 `font-variant-numeric: tabular-nums`。
- 图标全部来自 `lucide-react`，`stroke-width` 默认 2，尺寸写在括号里，例如 `Inbox(16)`。
- 最小字号 13；不出现 12 及以下的文字（`--fs-xs` 12 只能用于已存在的旧样式，新组件一律 13）。
- “按钮 sm”= 现有 `<Button size="sm">`：高 32、左右内边距 12、圆角 6（`rounded-md`）、字号 13、字重 500、图标 16、图标与文字间距 6。“按钮 icon-sm”= 32×32。

# 第一期：AI 任务与恢复

## 1. 任务卡 `TaskCard`

### 1.1 结构与尺寸（所有状态共用）

```
┌──────────────────────────────────────────────────────────────┐  ← 外框 1px，圆角 8
│ [图标16]  标题文字（13/500）                    时间（13 灰）│  ← 第 1 行，行高 20
│           说明文字（13/400，灰，可多行）                     │  ← 第 2 行，可无
│           [主按钮 sm]                       [ghost 按钮 sm] │  ← 第 3 行，可无
│           错误/提示行（13，彩色）                            │  ← 第 4 行，可无
└──────────────────────────────────────────────────────────────┘
```

- 容器：`display: grid; grid-template-columns: 16px 1fr; column-gap: 10px; row-gap: 6px; padding: 10px 12px; border: 1px solid <边框色>; border-radius: 8px; background: <底色>;`
- 图标在第 1 列，`align-self: start; margin-top: 2px`（让 16 的图标和 20 行高的标题居中对齐）。第 2–4 行都从第 2 列开始。
- 第 1 行：`display: flex; align-items: baseline; gap: 12px;` 标题 `flex: 1; min-width: 0; font-size: 13px; font-weight: 500; line-height: 20px; color: <标题色>;` 超长时最多两行，`-webkit-line-clamp: 2`。时间 `flex: none; font-size: 13px; color: #b8b8c2; tabular-nums;`
- 第 2 行（说明）：`font-size: 13px; line-height: 1.6; color: #b8b8c2;` 最多 3 行，超出省略，完整内容放 `title`。
- 第 3 行（按钮行）：`display: flex; align-items: center; gap: 8px; margin-top: 2px;` 主按钮靠左；“重新生成…”用 `margin-left: auto` 推到最右。**两个按钮之间的最小水平距离 48**，卡片宽度不足时（容器 < 320）按钮行改为纵向：主按钮在上，`重新生成…` 在下并左对齐，二者间距 8。
- 第 4 行（错误/提示）：`font-size: 13px; line-height: 1.6;` 颜色见各状态。前面带 `AlertCircle(14)`，图标与文字间距 6，图标 `margin-top: 3px`。
- 卡片宽度：随父容器拉伸（`width: 100%`），最大 640；在对话区里最大宽度 95%。
- 整卡 `role="status"`，`aria-live="polite"`；状态变化时由屏幕阅读器读出标题。

### 1.4 三点动画（沿用现有 `.ai-thinking-dots`）

- 三个 6×6 圆点，间距 4，颜色 `currentColor`（`#b8b8c2`），整体 26×6，垂直居中放在 16×16 图标格内（`margin-top: 7px`）。

### 1.5 “重新生成…”行内确认

点击后**按钮行被替换**（卡片高度增加，不弹窗）：

```
│           会新建一个 AI 任务。原任务和已有结果都会保留；            │
│           如果原任务之后也写入，两份结果都在。                    │
│           [确认重新生成]  [取消]                                 │
```

- 说明文字 13/1.6，`#fafafa`。
- `确认重新生成`：按钮 sm，variant `default`（白底 `#fafafa`、字 `#18181b`），图标 `RotateCcw(16)`。
- `取消`：按钮 sm，variant ghost。两按钮间距 8，左对齐。
- 确认区出现时焦点移到 `取消`（防误触 Enter）；Esc 等同取消且 `preventDefault`，不触发工作台的 Esc 返回地图。
- 确认后卡片立刻进入 S14 叠加态；新任务的卡片出现在**原卡片正下方**，间距 8。

## 2. 任务卡出现的位置

### 2.1 小课 · 空状态（尚无小课）

现有空状态是垂直居中的一列：44×44 图标块 → 标题“从一个小例子开始”（17/600）→ 说明（14/1.75，最大 42ch）→ 按钮。

- 有任务时：**“生成小课”按钮被任务卡替换**，任务卡宽 420（最大 100%），左对齐文字（卡片自身居中）。标题、说明、图标块保持不变。
- 任务进入 S9 后：小课出现，空状态自动切换为小课视图，不再显示任务卡。
- 任务处于 S4/S5/S6/S10/S11/S12 时，任务卡下方 12 处再显示一行 `t-meta`：`也可以在右上角「AI 任务」里查看全部记录。`

### 2.2 小课 · 补一节

- 位置：小课标签栏（`.lesson-tabs`，下边框 1px）正下方、iframe 正上方；`margin: 8px 16px; align-self: stretch;`（即现有 `.lesson-thinking` 的位置与尺寸）。
- 同时可有多张（例如一张 S4、一张 S2），纵向堆叠，间距 8，最多显示 2 张，第 3 张起折叠成一行：`还有 {n} 个 AI 任务 · 查看`（13，`#b8b8c2`，“查看”打开任务弹层）。
- S9 状态的卡片：新小课标签出现并被选中后，卡片 **保持 4 秒** 再以 200ms 高度+不透明度收起；收起只是从这里移走，记录仍在任务弹层。减少动效时直接移走。
- 标签栏里由任务写入的新标签：悬停 `title` = `{标题}\n由 AI 任务写入 · {时:分}`。

### 2.3 对话（NodeChat）

现有消息区：`padding: 16px 20px; gap: 16px`；用户气泡 `max-width: 88%`，`#2a2a2f` 底，圆角 12（右下 2），`padding: 8px 12px`，14/1.7。

- 气泡下方 16 处，左对齐：13 灰字 `AI 导师`（与现有一致），其下 4 处放任务卡，`max-width: 95%`。

- 失败类状态：任务卡留在消息流里，位于该用户消息之后；后续新消息继续排在卡片下方。
- 输入框：任务处于 S1–S3、S7 时，发送按钮禁用，`title` = `上一条还在等 AI 回复`；输入框本身可继续输入。

### 2.4 练习验收（PracticePanel）

- 出题/换题：替换题目段落（`.practice-question > p`）的位置，卡片宽 100%。“换一道题”链接在任务期间禁用。

- 判卷任务 S9 后：卡片换成现有的判定结果卡。

### 2.5 知识桥（BridgeDetail）

- 位置：“用 AI 补充知识桥”按钮所在位置；按钮被任务卡替换，卡片宽 100%（面板内宽约 370）。

- 本期不做单桥补全、缺项条、预览。

### 2.6 全局进度条（右下角 `.busy-indicator`）

- 只用于**非 AI** 的普通保存（现有行为不变）。AI 任务不再显示在这里，改由各自的任务卡和任务入口显示。
- 生成地图、生成主线、找回思路总结这三类没有固定“结果位置”的任务：卡片显示在课程头下方的提示条区域（见 4 节），而不是右下角。

## 9. 图形渲染 `DiagramView`

### 9.1 通用

- 输出单个 `<svg>`，`viewBox` 取后端给的宽高，`width: 100%; height: auto; max-height: 100%`。
- 字体：`--font-sans`，元素文字 14；数值/矩阵元素用 `--font-mono` 14，tabular-nums。
- 默认描边 `--diagram-stroke #8a8a94`，1.5；文字 `#fafafa`；方框填充透明。
- 不渲染任何后端未声明的元素类型；未知类型跳过，并在图形区右上角显示 13 灰字 `有 {n} 个元素无法显示`。

### 9.2 元素外观（元素集合以 Codex 定稿为准，这里给出前端画法）

| 元素 | 画法 |
| --- | --- |
| 方框 box | 圆角 6 矩形，描边 1.5 `#8a8a94`，填充透明；标签居中 14 `#fafafa` |
| 单元格 cell（矩阵/表格） | 无圆角矩形，描边 1 `#34343b`，内容居中 mono 14；整组矩阵两侧画方括号（2px `#b8b8c2`，括号臂长 8） |

| 箭头 arrow | 1.5 `#8a8a94` 直线 + 实心三角箭头（8×8）；标签在线段中点上方 6，13 `#b8b8c2` |

| 点 point | 半径 4 实心 `#fafafa`；标签右上 6，13 `#b8b8c2` |

### 9.3 本步变化的标示

- **改动元素**：描边改为 2px `#fbbf24`；方框/单元格内填充 `rgba(251,191,36,.10)`；文字仍 `#fafafa`。
- **被移除或被替换的旧值**：在同位置显示旧值，`#b8b8c2` 不透明 .55，加删除线（单元格内居中一条 1px `#b8b8c2` 横线，长度为文字宽度 + 4），新值写在旧值右侧或下方（由后端坐标决定）。只在当前步显示，下一步消失。
- **新增元素**：同改动元素，无旧值。
- 第 1 步无任何琥珀标示。
- 缩略图（例图卡、横向带）里不显示琥珀标示，只画第 1 步。
