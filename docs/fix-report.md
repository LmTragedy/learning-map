基于当前工作区代码（未提交改动）阅读 + 本地 8741 实际运行观察。每项给出「根因 → 修法 → 涉及文件 → 工作量」。

## 1. 笔记不像 Notion：没有标题选择、颜色等

**根因**
- 编辑器是 CodeMirror 纯 Markdown（`LiveMarkdownEditor.tsx` + `liveMarkdown.ts`），只做了“光标离开后隐藏 `#`、`**`”的装饰，本质还是源码编辑器。
- 没有任何格式入口：无工具栏、无 `/` 命令菜单、无选中浮动条、无块拖拽。用户必须会 Markdown 语法。
- 颜色在 Markdown 里没有标准语法，且阅读视图 `MarkdownNoteEditor.tsx` 用了 `skipHtml`，就算写 `<span style>` 也会被丢掉。
- 三个显示模式（实时预览/源码/阅读）对普通用户是噪音。

**修法（二选一，推荐 A）**

| | A. 换块编辑器（推荐） | B. 在 CodeMirror 上补工具 |
|---|---|---|
| 方案 | Tiptap（ProseMirror）或 BlockNote，`/` 菜单、浮动格式条、H1–H3、列表、待办、引用、代码、文字色/背景色、拖拽块 | 加顶部工具栏 + `/` 菜单 + 选中浮动条，命令往文本里插 Markdown；颜色用自定义语法如 `{red}文字{/}` |
| 体验 | 接近 Notion | 仍是“看得到符号”的编辑器 |
| 存储 | 仍存 Markdown 字符串（`tiptap-markdown` 序列化），颜色写成白名单 `<span data-color="red">`；阅读视图改为白名单 HTML（rehype-sanitize）而不是 `skipHtml` | 不变 |
| 兼容 | 旧笔记按 Markdown 导入，无需迁移；后端 `personal_note` 字段与 100,000 字限制不变 | 完全兼容 |
| 工作量 | 中（2–3 天） | 小–中（1–2 天），但上限低 |

**附带**
- 去掉“实时预览/源码/阅读”三按钮，只留一个“查看 Markdown 源码”折叠项。
- 自动保存：输入停止 1.5s 自动保存到课程（现在必须手点「保存笔记」），冲突逻辑沿用 `noteDrafts.ts`。
- 涉及：`LiveMarkdownEditor.tsx`、`MarkdownNoteEditor.tsx`、`PersonalNote.tsx`、`nodeNotes.css`、`package.json`。

## 2. UI 布局奇怪

**观察到的问题**
- 三栏：左侧课程栏 240px + 中间地图 + 右侧节点栏 380px。打开笔记/小课时，内容被 portal 到地图区域（`styles.css:532-534`）把地图盖掉，但右侧节点栏仍在 —— 正文被夹在两栏中间，看起来像“半个页面”。
- 顶栏按钮堆叠：目标看板 / 复习所选 PDF / 导入材料 / 更多，层级平铺，主次不明。
- 重要功能放在弹窗里：目标看板、课程笔记都是 `modal`（`App.tsx` 底部 `modal-wide`），弹窗里再有三列看板 + 详情侧栏，空间很挤。
- 左栏底部「课程笔记」「Obsidian 笔记」两个“笔记”并列，用户分不清。
- 右侧节点栏信息过长：状态徽章、关系、综合节点、摘要、再到 小课/学习对话/练习验收 三个标签，核心操作要滚很远。
- 移动端底栏只有 地图/复习/档案/设置，**没有目标、没有笔记**；「复习所选 PDF」按钮在窄屏被隐藏。

**修法**
1. 课程内改为顶部一级标签：**地图 | 目标 | 笔记 | 材料**（替代目标看板弹窗、课程笔记弹窗、材料弹窗），每个都是整页视图。
2. 打开节点笔记/小课时进入“专注模式”：隐藏右侧节点栏（或收成 48px 图标条），正文居中、最大宽 760px。
3. 顶栏只保留：课程名 + 进度 + 「导入材料」主按钮 + 「⋯」。复习模式放进地图工具栏。
4. 节点栏重排：标题 → 状态 → 主操作（开始学习 / 笔记 / 验收）→ 标签页；关系、综合节点放进可折叠区。
5. 移动端底栏改为：地图 / 目标 / 笔记 / 更多。
6. 「Obsidian 笔记」改名为「Obsidian 导入/导出」并移入设置或「⋯」。

涉及：`App.tsx`（拆分为 `CourseHeader`、`CourseTabs` 等，它已 1616 行）、`NodePanel.tsx`、`styles.css`、`nodeNotes.css`、`goals.css`。工作量：中（2–3 天）。

## 3. 目标看板和主功能联动太弱

**根因**：只有单向链接 —— 目标 → 节点（`GoalDetail.tsx` 的「进入节点」「学习对话」）。反方向全部缺失：
- 节点栏看不到“这个知识点属于哪些目标”。
- 地图上无法按目标过滤/高亮。
- 「建议下一步」（`route`）完全不考虑目标，进行中的目标对学习路线没有影响。
- 关联节点全部验收通过、小目标全勾完时没有任何提示。
- 只能在目标编辑器里勾节点（长长的 checkbox 列表），不能在节点上“加入目标”。
- 小目标不能关联节点，只能手动勾选。

**修法**
1. **节点栏「所属目标」**：节点标题下显示目标 chip，点击跳到目标；加「加入目标…」下拉。前端可直接从 `course.goals[].node_ids` 反查，无需改后端。
2. **地图按目标聚焦**：地图工具栏加“目标”下拉；选中后只高亮该目标节点（复用 `nodeVisibility.ts` 的过滤思路），其余变淡。
3. **当前目标驱动推荐**：`backend/route.py` 计算建议时，优先“进行中”目标里先修已满足的节点；顶栏显示当前目标 + 进度条。
4. **完成提示**：关联节点均验收通过且小目标全勾时，卡片显示“可以确认完成”横幅（仍需用户点确认，与现有规则一致）。
5. **小目标可关联节点**：subtask 增加可选 `node_id`，节点验收通过时自动勾上（可在设置里关掉）。需改 `goals.py`、`schemas.py`、`types.ts`。
6. 看板卡片支持拖拽换列（README 已注明尚未实现）。

工作量：1、2、4 小（各半天）；3、5 中（各 1 天）；6 小。

## 4. 笔记功能出口难找

**根因**
- 笔记打开后，唯一的退出是左上角一个 `ghost` 小按钮「返回地图」（`PersonalNote.tsx` header），颜色很淡。
- **Esc 不能关闭笔记**，也不能关闭任何弹窗：全局 `keydown`（`App.tsx:161-176`）的 Escape 只关菜单和移动端侧栏。
- 浏览器“后退”无效：笔记/小课/目标都是组件状态，没有 URL，后退会直接离开应用。
- 笔记入口也分散：节点栏的「节点笔记」按钮 + 左栏底部「课程笔记」弹窗，二者关系不直观。

**修法**
1. 笔记顶栏改为面包屑：`课程 / 节点名 / 笔记`，每段可点；右上角明显的 ✕ 关闭按钮 + 保存状态。
2. Esc：笔记、小课阅读、所有 modal 都可 Esc 关闭（有未保存草稿时仍保留草稿，不弹确认）。
3. 加轻量 hash 路由（`#/course/:id/node/:nid/note`、`#/course/:id/goals`），浏览器后退可退出笔记，链接可直接打开。
4. 与第 2 点合并：「笔记」成为课程一级标签，列出所有节点笔记，可搜索。

涉及：`App.tsx`、`PersonalNote.tsx`、`NodePanel.tsx`、`CourseNotes.tsx`。工作量：小–中（1 天）。

## 5. 便捷基础功能缺失

当前全项目只有 `Ctrl+K` 一个快捷键，且没有任何“全选”。逐项清单：

| 功能 | 现状 | 修法 | 位置 |
|---|---|---|---|
| 全选 / 全不选 | 无 | 加「全选」三态复选框 | 目标编辑器关联节点（`GoalEditor.tsx`）、候选目标（`GoalCandidates.tsx`）、复习选 PDF（`App.tsx:1050`）、材料列表 |
| 列表内搜索 | 目标编辑器的节点列表无搜索，节点多时（comp4418 有 54 个）很难找 | 顶部过滤框 + 按周次/阶段分组 | `GoalEditor.tsx` |
| Ctrl+S 保存 | 无 | 笔记、目标编辑器响应 Ctrl+S | `PersonalNote.tsx`、`GoalEditor.tsx` |
| 自动保存 | 笔记需手动保存 | 防抖自动保存 | 见第 1 点 |
| Esc 关闭 | 无 | 见第 4 点 | `App.tsx` |
| 笔记搜索 | 课程笔记弹窗无搜索 | 全文搜索 + 高亮 | `CourseNotes.tsx` |
| 删除/清空笔记 | 只能手动删空再保存 | 「清空笔记」（保存前已有课程版本可恢复） | `PersonalNote.tsx` |
| 目标删除 | 需确认现状 | 详情里加删除（带确认） | `GoalDetail.tsx`、`goal_routes.py` |
| 批量操作 | 无 | 目标多选后批量移列/删除 | `GoalBoard.tsx` |
| 快捷键帮助 | 无 | `?` 打开快捷键列表 | 新组件 |
| 撤销提示 | 移动目标、勾小目标无撤销 | 操作后 toast「已移动 · 撤销」 | 新增 toast 组件 |

## 建议修复顺序

1. **第一批（1–2 天，立刻改善体感）**：Esc 关闭 + 笔记 ✕/面包屑 + 全选 + 节点列表搜索 + Ctrl+S + 节点栏「所属目标」 + 完成提示。
2. **第二批（2–3 天）**：布局重排 —— 课程一级标签（地图/目标/笔记/材料）、专注模式、移动端底栏、拆分 `App.tsx`。
3. **第三批（2–3 天）**：笔记换块编辑器（Tiptap/BlockNote）+ 自动保存 + 颜色。
4. **第四批（1–2 天）**：目标驱动推荐、地图按目标聚焦、小目标关联节点、拖拽。

每批完成后跑 `npm run typecheck`、`npm run lint`、`frontend/tests/*.test.mjs`、`pytest tests/`，并在浏览器实测。
