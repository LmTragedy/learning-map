# Learning Map · 本地知识地图

MIT 开源的单用户本地学习应用，使用 React Flow 地图、FastAPI 和 SQLite。所有课程资料、对话、验收和评分默认保存于项目 `data/`，不进入 Git。当前为 0.1.0 开发版。

## 启动

已安装依赖的这台 Windows 电脑，可以双击 `start.cmd`，或在 PowerShell 运行：

```powershell
cd D:\记忆库\learning-map
.\start.cmd
```

打开 <http://127.0.0.1:8741>。保留终端，Ctrl+C 停止；重启使用同一命令。此入口使用固定端口 8741，直接调用项目 Python，不受 PowerShell 的 `.ps1` 执行策略影响，也不修改执行策略。

原有 `start.ps1` 和 `stop.ps1` 仍保留，供允许执行 PowerShell 脚本的环境使用。若 `start.cmd` 报告端口已占用，先打开上述地址检查是否已经运行。需要其他端口时，在项目目录直接运行：

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.app:app --host 127.0.0.1 --port 8742
```

新电脑需要 Python 3.13、Node.js 22 或更新版本、npm；AI 模式需要安装并登录 Codex 桌面版，或安装并配置 Codex CLI。在允许执行 PowerShell 脚本的环境先运行 `./setup.ps1`，再运行 `./start.cmd`。本次验证环境为 Windows / Python 3.13 / Node 24；未做其他系统或干净电脑安装验收。安装脚本使用全局 Python 的 pip 安装到项目虚拟环境，不需要改全局包。

## 使用

1. 创建课程，向同一学科追加多份 PDF。导入只复制文件，不移动或改写原件。可选择周次。没有材料时可试用明确标注的数据库示例；其节点由人工编写、初始零进度，不是 AI 生成结果。
2. 在设置中开启 AI。开启前会说明资料节选、对话、作答与纸面图像会发送至 Codex 配置的提供方。本地优先指数据归属和持久化；使用远端模型时推理不在本机。Codex 本身也会在其用户目录保存会话，本应用删除课程不会清除该记录，保留策略由 Codex 和提供方设置管理。本应用默认中等推理力度，模型使用本机 Codex 配置。未开启 AI 仍可查看来源、自我标记、使用精确 Recall 和管理课程版本。
   Windows 下先在命令路径中查找 Codex；未找到时，自动检查当前用户本机 Codex 桌面版的版本目录，不依赖固定用户名或版本号。界面“Codex 已找到”只表示程序和 app-server 检查通过，登录/实际模型请求仍需分别验证。更新此适配器后，需停止并重新启动本地学习服务，再刷新网页。
   设置中的“模型 / 提供方”填写模型标识，例如 `gpt-6.1-terra`；“推理力度”可选低、中等、高。模型与推理设置保存在本软件中，不修改全局 Codex 配置；后续新建及恢复的节点会话都会使用所选配置，原有对话保留。
3. 生成或更新地图。现有节点 ID、对话和进度保留；新增概念追加。相同标题只追加来源，并标为合并待核对，不覆盖原节点含义/进度。AI 先修关系是推断，不是经过验证的教学顺序。
4. 默认进入「学习主线」：按先修层级分阶段，当前阶段展开，其余可折叠；建议下一步只选择所有先修已满足的节点。阶段是导航分组，同阶段可能有并行内容。「完整关系图」保留全部节点和依赖，按先修层级分列并用阶段分区，打开时定位到当前节点；悬停或选择节点会高亮整条先修链和后续链，可「只看相关」、看全图或按周次直达。两个视图里的锁定节点都隐藏标题和说明，通过先修、复习模式或临时直达后才显示。
   点选节点后，在「小课」生成 Teach HTML 学习网页：具体例子、分步解释、自测题和可展开的参考思路。网页保存在当前节点，可重新打开、下载；说明卡点后可追加补充小课。生成需要启用 AI，读取已保存网页不需要 AI。生成上限按当前节点已有的 20 节小课检查；严格复习时按资料组合单独计算，补充不会自动增加地图节点。阅读标记只记录已读，不自动改变掌握状态。
   学过仍需补充与验收；自我掌握跳过该节点且解锁后续，和系统验收通过、用户确认通过、待复查分别保存。原有学习对话和练习入口保留，直达只临时进入目标，不扩散解锁。
5. 使用节点题目作答，可附照片/PDF及文字参考答案。没有答案时提示模型先分析求解，再检查思路、步骤和结果。不确定结果交由用户选择，不自动判通过。每次验收可单项/双项评分或跳过；每十次实际评分形成阶段建议，接受前不改教学偏好。
6. Recall 显示当前节点实际保存的对话。明确说忘记时先引用最近实际发言；没有生成式心理推测或虚构历史。恢复课程会清除旧 Codex 会话标识，以恢复后的记录建立新会话，避免读到恢复时间之后的隐藏历史。
   Recall 中可点击“整理学习内容”，使用实际保存的节点历史生成学习脉络；每项标为 AI 归纳，可展开引用原文。服务端拒绝跨节点、不存在、重复的引用，也拒绝把 AI 发言标成用户想法。引用 ID 和角色校验不能证明归纳语义一定正确，仍需对照原话；整理不代表已掌握，也不修改原对话、验收或评分。本次整理只在当前窗口展示，没有历史或未启用 AI 时不会生成虚构内容。

## 按 PDF 复习

在课程顶部点击“复习所选 PDF”，勾选已经导入的 PDF，再点击“开始复习”。地图只显示至少引用一份所选 PDF 的节点；可以直接复习已学、已掌握或尚未解锁的相关节点，先修关系与原有掌握记录仍然保留。没有匹配节点时会提示更换资料；若材料尚未生成地图，需要先生成地图。

默认开启“AI 仅参考所选资料”：应用仅向 AI 提供所选 PDF 的节点来源，以及同一资料组合下产生的对话、验收和小课。AI 仍能看到课程/节点名称、用户自我标记、节点的课程整体验收状态和已同意的教学偏好；这些是学习背景，不是 PDF 原文证据。旧的综合节点简介会标明为跨材料概览，不作为严格范围的 AI 依据；用户主动输入的内容与上传的作答仍会发送。不同 PDF 组合使用独立的节点会话与题目，返回相同组合可以继续；旧记录保留，Recall 可以查看全部原话，AI 整理只使用当前组合的对话。关闭此选项时仅筛选节点，AI 沿用整门课程的节点上下文与会话。

严格模式的验收结果单独记录为“当前资料范围验收通过”，不把部分材料的通过扩大为整节点掌握或解锁；自我标记仍适用于整个节点。查看其他范围的小课或继续其评分，需要退出复习或切回原组合。选择会保存到本机并随课程版本恢复；退出复习即可查看完整课程，不必重新导入，不会重置进度。生成/补充整门课程地图仍分析全部材料，不受复习筛选限制。模型可能有自身知识与判断误差；此开关控制应用提供的资料与历史范围，不代表对模型输出的逐字保证。

## Codex 会话命名与分组

后续节点对话使用“课程名｜节点名”；地图生成使用“课程名｜知识地图生成”，出题、验收和 Recall 整理会追加用途后缀。恢复节点会话时也会同步规范标题。模型与推理力度继续使用本软件设置。

Codex app-server 的原生 section 元数据会按“学习 · 课程名”归组。但本机实测发现，它与桌面侧栏的自定义分组并非同一个 ID，原生移动不会自动更新桌面分组条目。已通过 Codex 桌面工具整理的现有会话可以在课程侧栏组内找到；未来新会话可保证自动命名，不能保证自动进入桌面侧栏课程组，可在 Codex 中手动移动。没有绕过官方接口去改写 Codex 内部偏好文件。

## 解析、保真与保护

- PDF 默认使用 pypdf 提取文字，pypdfium2 渲染原页；扫描页/照片使用本地 Tesseract.js OCR。首次 OCR 可能下载英文/简体中文语言包，随后使用 `data/ocr-cache`。离线且没有缓存会明确报告未识别，不冒充成功。公式、图表和排版必须回原页核对；所有自动提取均标注不确定，不能保证一字不差。
- Docling 是可选实际适配器，默认未安装、未实测。不要把可选列表视作已完成接入。[组件与核验来源](docs/components.md) 记录集成情况与许可。
- 一次导入最多 10 文件、单文件 50 MB、PDF 200 页；纸面作答一次最多 6 页。地图材料上下文合计 180,000 字符，超过时拒绝而不是静默截断。本版不适合直接导入整部大型扫描教材。
- 每次生成地图或保存新小课前保存整门课程版本；恢复前保存当前完整状态。课程资料和作答副本不可变且保留供历史版本使用。恢复同时还原地图、小课、对话、验收、评分及该课程偏好。全局档案从当前课程计算，因此删除/恢复会改变评分批次。
- 删除先列出影响内容并确认，从活动列表移入本地回收状态；原件和本地回收数据保留，本版无彻底擦除按钮，也没有回收区恢复界面。
- Obsidian 只读取设置中的本地库。写入必须先预览准确路径和内容，再确认；本版只新增到已有目录，拒绝覆盖现有文件。笔记参与地图生成的策略尚未确定，因此不会自动纳入。
- 服务只绑定回环地址，拒绝外部 Host、跨来源请求及没有应用标记的写操作。Codex 使用独立空目录、只读权限、拒绝审批和工具尝试；当前协议没有完整的内置工具禁用清单，不能宣称绝对隔离或完全无只读工具尝试。

## 开发与验证

```powershell
.venv\Scripts\python.exe -m pytest -q --basetemp=test-results/pytest-local
.venv\Scripts\python.exe -m ruff check backend tests scripts
cd frontend
npm run typecheck
npm run lint
npm run build
node --test tests/graphLayout.test.mjs
```

先创建 `test-results` 目录。默认测试使用临时课程和真实 SQLite/文件。AI 自动化测试在外部协议/模型边界提供脚本响应，验证状态规则，不能证明模型质量。OCR 测试需要已安装本地 worker 和语言缓存；未满足时明确跳过。`scripts/verify_live.py` 是显式调用真实 Codex 提供方的合成课程集成验收，会消耗模型额度，结果保存在被 Git 排除的 `test-results/live-flow/`。

材料包括文字 PDF（公式和表格）、栅格扫描 PDF 和打印内容模拟纸面照片；它们不代表真实手写、复杂多栏论文或任意公式的识别质量。没有用用户私人课程材料做模型验收。

## 默认值与当前边界

难度先显示“初始估计”，没有已验证的难度权重公式。阶段建议目前是按评分和实际记录生成的规则建议，不宣称 AI 已发现学习规律；采用后只是改变后续提示中的教学节奏，效果需继续验证。连续两次通过/未通过也仅提出建议。跨学科总图、多设备同步、语音输入、备份导入导出及复杂节点合并/拆分编辑仍不在此版。

架构和职责见 [architecture.md](docs/architecture.md)，界面基准见 [design-language.md](docs/design-language.md)。无提交、推送、发布或部署脚本。
